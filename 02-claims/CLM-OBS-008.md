# CLM-OBS-008

record_state: CURRENT
status: SUPPORTED
confidence: HIGH

Proposition:
In at least one strong capillary-fed boiling comparator, repeated dryout changes the subsequent surface-wetting / capillary state and materially reduces later CHF, so dryout history can be an input to degradation-state reasoning rather than only a transient failure marker.

supporting_sources:
- PAPER-CN-DRY-001

Boundary:
this is demonstrated for the tested laser-machined capillary-fed boiling surface and its reported contamination / rewetting mechanism; it is not proof that the same chemistry or magnitude occurs inside every sealed copper-water phone vapor chamber.
