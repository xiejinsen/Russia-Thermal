# Content & Image Policy

status: DESIGN
scope: presentation content, images and provenance

## 1. Content hierarchy

Every page should follow:

1. one-line conclusion;
2. 3–5 decision-relevant facts;
3. visual / comparison;
4. expandable technical detail;
5. evidence links.

## 2. Institution content

Prefer:
- institution/lab name;
- key people;
- capability;
- collaboration role;
- representative evidence;
- risk/boundary.

Avoid:
generic institutional history unless it changes partner judgment.

## 3. Scholar content

Prefer:
- verified current role;
- why they matter;
- top themes;
- representative works;
- collaboration context;
- recommended role.

Avoid:
raw publication lists.

## 4. Evidence content

Every evidence card distinguishes:
- **direct reported result**;
- **project inference**;
- **boundary / caveat**.

Do not visually collapse these into one paragraph.

## 5. Images

Priority order:

1. original project diagrams;
2. official institution/lab images with acceptable use;
3. official researcher portraits with source attribution;
4. paper figures only when reuse is legally appropriate.

Default:
do **not** copy paper figures merely because they improve visual appeal.

## 6. Image metadata

Every web image record requires:
- subject;
- source URL;
- local path if stored;
- attribution;
- license/use status;
- alt text;
- crop/focal guidance if needed.

## 7. Scholar portraits

Portraits are optional.

Missing portrait must have a designed fallback:
- initials;
- institution mark;
- neutral silhouette.

No layout should break because one scholar lacks an image.

## 8. Diagrams

Prefer original diagrams for:
- Russia × China capability map;
- collaboration architecture;
- institution→lab→people hierarchy;
- mechanism flow;
- Keep/Reserve/Watch/Kill portfolio.

Diagrams must be generated from or cross-checked against canonical data.

## 9. Paper thumbnails

If no reusable figure:
use a designed evidence thumbnail based on:
- source type;
- technology tags;
- institution;
- year.

This gives visual consistency without copyright risk.

## 10. Attribution display

Attribution may be:
- visible under image;
- in image detail modal;
- on source page.

It must remain discoverable.
