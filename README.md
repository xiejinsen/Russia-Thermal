# Russia Mobile Thermal Technology & Collaboration Insight

Evidence-backed research on Russian capabilities that may contribute to next-generation **smartphone thermal management**, with tablets as a secondary reference platform.

## Core question

> What differentiated Russian research capabilities can complement Chinese/mobile-industry strengths and create new, testable thermal-management innovations for smartphones?

This is **not** a ranking project. The decision outputs are:
1. technology map;
2. Russian institution / lab / researcher map;
3. Russia–China capability-gap map;
4. open-problem and innovation-hypothesis map;
5. collaboration targets, PoCs and 3-year R&D directions.

## Scope

- Primary platform: **smartphones**
- Secondary platform: **tablets**
- Other domains: only as sources of transferable technology
- Main evidence window: **2021–2026**
- Priority window: **2023–2026**
- Older work: only for technical lineage / foundational mechanisms / lab capability

## Technology tracks

1. Passive thermal management
2. Active air cooling
3. Emerging active cooling: MEMS / piezo / synthetic jet / EHD / thermoelectric / microfluidic
4. Fundamental heat & fluid science
5. Thermal materials
6. Software / predictive thermal control
7. Thermal–acoustic–mechanical co-design

## Evidence language

Important statements are tagged conceptually as:
- **Source fact**
- **Author/company claim**
- **Cross-source observation**
- **Analyst inference**
- **Hypothesis**

Absence of public evidence is recorded as uncertainty, not as evidence of absence.
