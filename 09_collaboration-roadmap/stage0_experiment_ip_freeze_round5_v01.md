# Round 5 — Stage-0 Experiment / Foreground-IP Freeze Review v0.1

Last updated: 2026-10-05

Status: **FROZEN FOR OUTREACH**

Purpose:
minimize Stage-0 experiments and prevent broad foreground-IP theses that collide with known prior art.

This is technical prior-art strategy, not legal FTO or patentability advice.

## 1. Global freeze rules

A partner question or experiment remains only if it can change one of:
- GO / HOLD / KILL;
- experiment-arm selection;
- process/product compatibility;
- foreground-IP boundary;
- Stage-1 promotion.

Remove curiosity questions, already-public capability questions and duplicated measurements that cannot change a decision.

## 2. Minimal experiment set

profile → DI water → vacuum/degassing → mass/wetting retention → confined rewetting/dryout.

## 4. Foreground-IP collision review

### Pavlenko

Known crowded territory:
- capillary/porous coatings;
- hydrophilic surfaces;
- modified mesh;
- composite ultra-thin VC wicks;
- wettability-engineered liquid return.

Preliminary narrow whitespace:
**product-fluid-specific irreversible-dryout / rewetting control under sub-mm confinement with a surface state proven to survive phone manufacturing history.**

Required ingredients:
- sub-mm geometry constraint;
- defined working-fluid/material pair;
- manufacturing-state retention;
- measured irreversible-dryout/recovery behavior;
- topology/process narrower than generic surface enhancement.

### MPEI

Known crowded territory:
- nanoparticle coatings;
- microgroove/nanoparticle hierarchy;
- wettability tuning;
- composite/graded capillary structures.

Preliminary narrow whitespace:
**phone-scaled hierarchy whose measurable post-manufacturing capillary state predicts later dryout-margin degradation.**

Required ingredients:
- phone-scale geometry;
- measurable capillary/surface state;
- aging/process transition;
- predictive relation to a device failure margin;
- not merely lower thermal resistance.

### TPU

Direct prior-art collision:
mobile VC patents already disclose hydrophilic/hydrophobic layer or pattern architectures and self-driven liquid routing.

Therefore generic biphilic VC is frozen as non-foreground territory.

Preliminary narrow whitespace:
**low-organic / vacuum-stable copper surface state whose spatial wetting function survives actual VC manufacturing and provides repeatable confined rewetting advantage.**

Required ingredients:
- copper / thin geometry;
- low-outgassing process-stable state;
- before/after manufacturing-state definition;
- confined rewetting/failure metric;
- advantage beyond generic laser/oxidation reference.

### Lab 6.6

Direct background-IP collision:
Kutateladze already owns multiple gas + film + droplet electronics-cooling patents, including staged architectures.

Broad active two-phase cooling claims are therefore background/crowded territory.

Preliminary narrow whitespace:
**phone-budget-constrained power/volume/noise-aware actuation and control that changes the net thermal Pareto frontier.**

Required ingredients:
- fixed total electrical power;
- fixed total module volume;
- acoustic constraint;
- workload/load-state control;
- net advantage over passive reference.

## 5. Stage-1 promotion freeze

No route enters sealed Stage-1 unless all are true:
1. partner-data prerequisites closed;
2. geometry/process fit confirmed;
3. matched strong reference used;
4. repeatable n>=3 Stage-0 result;
5. product-fluid/process survival;
6. narrow foreground-IP thesis survives technical prior-art review;
7. no obvious background-IP / field-restriction blocker.

## 6. Patent-search exit rule

Reopen targeted patent search only after a specific Stage-0 winner exists.

Examples:
- a specific Pavlenko thin-mesh dryout topology survives;
- a quantitative MPEI aging predictor emerges;
- a TPU post-process wetting pattern survives and wins;
- a Lab 6.6 low-power system-control topology passes system budget.

Do not continue generic patent searching before a winning geometry/process exists.
