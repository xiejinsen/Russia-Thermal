## 2. First-contact objective

Determine whether TPU can fabricate a **thin-copper, low-outgassing, process-stable** laser/wettability pattern that preserves useful liquid-routing / rewetting function after sealed-VC manufacturing.

The 60-day boiler field test already demonstrates that the laser-process family can survive prolonged real-equipment exposure in another domain; the first meeting should focus on mobile-process transfer, not generic durability.

## 5. Do not ask

- proof that the laser process can survive any real environment — field validation already exists;
- generic contact-angle optimization without process-stability data;
- confidential chemistry composition if TPU can fabricate the coupon and provide a contamination-reviewable process declaration.

## 6. Continue / stop rule

**Continue if:**
- laser-only copper path is feasible;
- total functional height can fit <=150 μm;
- matched laser-only and biphilic coupons can be fabricated;
- process boundary is sufficient for contamination screening.

**Kill hydrocarbon branch early if:**
- vacuum/process stability is poor;
- measurable mass loss / contamination risk is unacceptable;
- wetting contrast collapses.

**Kill broad TPU phone thesis if:**
- copper transfer fails;
- generic laser/oxidation control matches both TPU branches.

## 7. Smallest experiment unlocked

Three arms:
- strong generic copper laser/oxidation control;
- TPU laser-only copper;
- TPU biphilic/hydrocarbon copper.

Sequence:
profile → DI water → vacuum/degassing → mass/wetting retention → confined rewetting/dryout.

## 8. Foreground-IP boundary

Target:
**low-organic / vacuum-stable copper spatial wetting topology that retains liquid-routing function after sealed-VC manufacturing**

Avoid:
- generic laser texture;
- generic biphilic surface;
- generic superhydrophobicity.
