## 2. First-contact objective

Do **not** start with a request for a phone prototype.

Ask whether the current gas-sheared film / staged gas-film-droplet architecture has a system operating point whose **total electrical power, pressure drop, complete volume and acoustics** are even compatible with a phone-scale feasibility study.

## 3. Mandatory questions

- useful gas and liquid flow ranges;
- channel + full-loop pressure drop;
- actuator/compressor electrical power;
- smallest complete expansion/nozzle/condenser/separator volume;
- liquid inventory;
- measured acoustic data if available;
- current integrated-prototype state.

## 4. Continue / stop rule

Continue only if a credible operating point exists that could fit a fixed phone-like total power and volume budget.

Otherwise remain mechanism/IP reserve.

No Stage-0 hardware spend before this plausibility screen.
