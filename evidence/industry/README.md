# Industry / Vendor Evidence Index

Last reviewed: 2026-10-05

## Purpose

Canonical home for industry-actor evidence that is not already a paper or patent card.

> **one original industry-relevant source → one Industry Source Card → reused by ID/link**

This is an evidence layer, not a vendor report or company-ranking layer.

## What belongs here

- official vendor/company technical webpages;
- official product/engineering disclosures;
- official company–university collaboration records;
- implementation/transfer records;
- official project/contract evidence that materially changes partner readiness;
- current company capability or product evidence used in a decision.

## What does NOT belong here

- papers → existing paper brief / 10Q layer;
- patents → existing patent brief / 10Q layer;
- broad decision synthesis → workstreams 03–09;
- generic low-value news → P2 registry evidence only when useful.

## Priority levels

### P0 — decision-changing
Create a full Industry Source Card when the source can materially change Stage-0 / Keep-Kill, partner readiness, industry-translation confidence, competitor-gap interpretation or productization confidence.

### P1 — decision-supporting
Create a shorter card when the source materially supports a current capability but does not independently change a decision.

### P2 — background
Do not create a full card by default. Keep minimal metadata in the source register or organization README if useful.

## Editing rules

1. One original source has one stable Industry ID.
2. Correct/update the existing card when the same source changes interpretation.
3. Do not create a second card because another workstream uses the same source.
4. Organization README files remain thin indexes, not narrative company reports.
5. Workstream decision files cite the Industry ID/card and keep only decision-relevant interpretation.
6. If an industry source is actually a paper or patent, link to the existing paper/patent card instead of duplicating it here.
7. Contradictory sources remain separate cards; the organization README records the contradiction.
8. Re-check current company/product facts before outreach or final recommendation.
