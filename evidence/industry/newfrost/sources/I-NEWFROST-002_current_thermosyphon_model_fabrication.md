# I-NEWFROST-002 — Current MPEI thermosyphon model fabricated by Newfrost

Priority: **P0**

Source type: **official MPEI proceedings / project evidence**

Source date: **2025**

## Source fact

Official MPEI proceedings for the current thermosyphon project state that the tested thermosyphon model was **manufactured by Newfrost LLC**.

## What this proves

- Newfrost participates in current physical hardware realization, not only historical contracts or paper coauthorship;
- the MPEI line has a public external-fabrication / engineering path.

## What this does NOT prove

- Newfrost fabricated the exact hierarchical coating itself;
- high-volume manufacturing;
- phone-scale manufacturability;
- transfer of the 42-month hierarchy to a commercial product.

## Decision impact

**Translation confidence: upgraded.**

The next partner question is which geometry/process/design elements came from MPEI specifications, which were standard Newfrost hardware, and whether the hierarchy/coating itself was part of the industrially fabricated model.

Do not ask the generic question 'does any Newfrost physical engineering interaction exist?' — this source closes it.
