# M3 — Online transient thermal-impedance condition monitoring

**[Online Condition Monitoring Methodology for Power Electronics Package Reliability Assessment](https://doi.org/10.1109/TPEL.2024.3352747)** — Henry A. Martin, Edsger C.P. Smits, René H. Poelma, W.D. van Driel, GuoQi Zhang — *IEEE Transactions on Power Electronics*, 2024.

## Background
Steady thermal resistance can hide where and when a thermal path is degrading.

## Technical method
A bounded transient heat pulse is used to extract temperature-dependent transient thermal impedance, with pulse duration selected to probe the desired thermal-path time scale.

## Main conclusion
Dynamic thermal response can reveal and localize package degradation online, with destructive/structural analysis used for validation.

## What this changes for this project
It gives a strong method analogy for a phone **thermal-health fingerprint** based on power→temperature response rather than a dedicated capillary sensor.

## Boundary
This is package/interface degradation evidence, not direct proof of two-phase wick-state estimation.
