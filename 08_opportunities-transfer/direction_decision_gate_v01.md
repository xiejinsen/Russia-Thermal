## H2 — target-fluid sub-mm phase-change / capillary control

**REFRAME + KEEP as Tier A**

### Rejected standalone novelty theses

Not sufficient as Russia-specific collaboration reasons:
- generic hydrophilic surface;
- generic biphilic surface;
- generic laser texturing;
- generic porous coating;
- generic composite wick;
- generic capillary/permeability gradient;
- generic low-resistance liquid channel.

### Surviving Tier-A thesis

> **working-fluid-transferable control of dryout / rewetting / wetting-state retention inside a sealed <0.5 mm-class device, proven beyond a strong modern UTVC reference.**

Lead:
Pavlenko/Kutateladze.

Why:
- deep HFE-7100 boiling/CHF/dryout evidence;
- negative wettability-retention evidence;
- thin surface IP;
- current active team.

### New geometry gate

Strong reference:
https://doi.org/10.3390/mi15050627

Reference includes:
- 0.39 mm finished UTVC;
- ~0.2 mm internal steam-channel/support height;
- 0.06 mm copper mesh.

Pavlenko geometry evidence:
https://doi.org/10.1134/S0040601525700454

Published mesh wire diameters include 100 and 220 um.

Therefore:
**published Pavlenko mesh hardware is not automatically a drop-in phone wick.**

The collaboration value is mechanism/process transfer to a thinner wick.

### Working-fluid gate

3M:
https://www.3m.com/3M/en_US/pfas-stewardship/operations-innovation/

3M completed PFAS manufacturing exit at end-2025.

Decision:
- HFE-7100 = legacy evidence/reproduction fluid, not default 3-year product fluid;
- water = first sealed copper-VC product-path reference;
- future dielectric fluid requires a separate sustainability/supply screen.

Downgrade H2 if the Russian advantage cannot transfer to a product-path fluid.

### Challengers

TPU:
- target-fluid biphilic/contrast-wetting;
- no direct public sealed/dielectric sub-mm evidence recovered so far.

MPEI Ivanov:
- current hierarchical/tunable coating;
- no direct public product-fluid/sub-mm VC evidence recovered so far.

MPEI ordered wick:
- pre-device until physical thin prototype and measured capillary/permeability exist.

### H2 advance gate

Advance only if:
1. functional element fits Stage-0 geometry or replaces another structural function;
2. useful behavior survives product-path fluid;
3. vacuum/process/cycling stability passes;
4. strong modern reference is improved;
5. narrow IP thesis remains.

Preferred foreground space:
- fluid-transferable wetting retention;
- <0.5 mm dryout/rewetting topology;
- moving-hotspot liquid routing;
- manufacturing-state retention;
- package/VC/system co-design.

### H2 kill/downgrade gate

Downgrade if:
- gain exists only in thick published geometry;
- gain exists only in legacy HFE-7100;
- scaling destroys permeability/capillarity;
- wetting state drifts after processing/cycling;
- China-style reference matches result;
- no narrow design-around/control point remains.
