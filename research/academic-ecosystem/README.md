# 数学物理学术生态调查｜维护规范与入口

## 1. 目标

检验既有俄罗斯热管理研究机构周边，是否存在可核查的数学、应用数学、理论力学、数学物理、计算数学、非线性动力学研究资源；以及这些资源是否通过人员、论文、项目、联合培养或共同实验室关系，实际连接到热管理研究。

本工作流只作为既有热管理研究的**旁证与机制解释**，不能替代热管理论文自身的证据，也不能单凭学校排名推断团队方法水平或手机产品优势。

## 2. 目录结构

- `README.md`：本调查的目标、维护规则和当前状态。
- `registry/institution-matrix.tsv`：机构候选总表；每行一所高校/研究机构，记录排名、研究资源、与热管理团队的关联和证据成熟度。
- `profiles/*.md`：机构档案；一机构一文件，保存官方单位、实验室、学者、可验证关联、缺口与来源。
- `evidence/source-register.md`：来源登记册，标记官方资料、排名、论文等证据类型及访问日期。
- `analysis/*.md`：每轮调研报告、比较结果、推论及反证。
- 后续如证据量增加，可按需添加 `people/`、`papers/` 或机器可读 claim/source 数据；当前不提前复制现有 Actor/Source 数据库。

## 3. 核心证据链

`原始来源 → 具体断言 → 学者/实验室/机构 → 与热管理团队的关系 → 热管理论文方法特征 → 有边界的结论`

必须分开记录以下四种证据：

1. **环境证据**：高校数学排名、数学/力学学科、研究生培养、学术城/科学院研究所生态。
2. **能力证据**：具体实验室的研究方向、代表论文、方法与成果。
3. **关联证据**：共同作者、双聘/兼职、联合培养、联合实验室、项目或可追溯的引用关系。
4. **传导证据**：热管理论文实际使用相关数学物理方法，且能追溯到该团队或学术网络。

排名只能支撑第 1 类，不能替代第 2–4 类。

## 4. 证据等级

- `A_OFFICIAL_DIRECT`：学校/实验室/科学院官方页面或原始论文直接支持。
- `B_PRIMARY_PUBLICATION`：原始论文、学术出版商或可核查学术数据库记录支持。
- `C_REPUTATION_OR_RANKING`：排名、声誉、一般性学校介绍；只作背景。
- `D_INFERENCE`：从空间邻近、研究方向相似等作出的推断，必须明确写为假设。
- `OPEN`：待查；不能写成事实。
- `CONTRADICTED`：已被可靠证据反驳。

## 5. 每个机构必须回答的问题

1. 数学/应用数学/理论力学的学科位置如何？排名来自何机构、哪一年、用什么口径？
2. 有哪些具体的数学物理、理论力学、计算数学、非线性动力学或流体力学实验室？
3. 哪些学者有可核查的代表性贡献？职务、单位和研究主题是否由官方资料确认？
4. 与已纳入热管理研究的团队是否有直接关联？关联类型和来源是什么？
5. 热管理论文中实际出现了哪些理论方法？是否能确认方法由相关团队开发/使用？
6. 是否有反例：理论实验室与热管理团队无可见联系、学校排名高但热管理论文以常规工程计算为主，或理论工作并不属于热管理？
7. 证据的时效、样本偏差、同一作者/团队重复计数问题是什么？

## 6. 维护规则

- 一个事实一条来源链；记录原始 URL、来源类型、页面/论文标题、发布日期（若有）、访问日期和支持的具体断言。
- 官方页面只能证明页面明确写出的内容。实验室存在不等于其所有成员参与某篇热管理论文。
- 人名、现任职务和单位须以官方个人页或近期论文作者信息核实；不凭同名自动匹配。
- 排名数据必须同时保存排名机构、年份、学科名称和名次；不同排名不可直接混算。
- 将事实与推论分段书写。没有联合论文/项目等直接证据时，写“关联尚未证实”，不能写“该实验室支撑了热管理团队”。
- 同一机构/团队的多篇论文用于说明研究连续性，不视作独立国家样本。
- 不把高校排名或实验室声誉当成国家整体数学物理优势的充分证据。
- 不新增外部联络、数据访问、合作承诺或产品性能主张；此工作仅使用公开资料。

## 7. 当前调查优先级

**Wave A（已启动）**
1. TSU：已有对流热质传递实验室和基础/数学物理中心的官方页面，适合检验“热传递团队—数学物理资源”关联。
2. NSU—新西伯利亚学术城—俄罗斯科学院西伯利亚分院研究所：检验高校与科学院数学/计算数学/水动力学网络。
3. TPU：核对热质传递实验室的解析解研究和数学建模资源。
4. MPEI：区分应用热工建模与更一般的数学物理理论资源。

**Wave B（随后）**
- Kutateladze Institute of Thermophysics 与 NSU/科学院学术城的可核查联系。
- ITP Ural、TSU 以外的既有热管理机构及其数学物理生态。
- 仅在有直接关系线索时增加其他高校，不以排名扩充名单。

## 8. 当前状态（2026-10-23）

- 已建立目录、登记规则与第一批官方来源。
- RAEX 2026 数学学科排名：NSU 第 6、TSU 第 10、TPU 第 15；这些仅是背景指标。
- TSU 的官方资料已确认对流热质传递实验室使用解析和数值方法；另有基础与数学物理中心。二者都在 TSU 内，但二者之间是否有人员/项目层面的实际协作仍需验证。
- TPU 官方实验室页面明确列出相变/热质传递问题的解析解，以及物理化学过程的数值模拟。
- NSU 与西伯利亚科学院研究所的联合培养网络有官方学术材料支持；具体热管理团队关联仍 OPEN。
- 本轮尚不能推出俄罗斯热管理团队整体具备领先的数学物理能力；传导证据仍是核心缺口。
