# Institution-First Entity Naming Standard v0.1

Last updated: 2026-10-05

Status: **CURRENT repository-wide naming / classification rule**

## 1. Purpose

Prevent people, teams and institutions from being displayed at the same hierarchy level.

All Russia-Thermal outputs must use the following hierarchy:

> **Institution → Team / PI / researchers → Capability / mechanism → Decision state**

Do not rank or compare a person directly against an institution.

---

## 2. Canonical display format

### Correct

**Kutateladze Institute of Thermophysics SB RAS**
- Pavlenko / Surtaev / Shvetsov / Zhukov team
  - dielectric boiling crisis / irreversible dryout
- Kabov / Kochkin / Chinnov team
  - shear-driven liquid film / instability / rupture

**National Research University Moscow Power Engineering Institute (MPEI)**
- Ivanov / Kuzma-Kichta / Alyautdinova team
  - hierarchical evaporator surfaces / long-term aging

**Tomsk Polytechnic University (TPU)**
- Feoktistov / Orlova team
  - laser / wettability-pattern surface engineering

### Incorrect

- Pavlenko
- MPEI
- Kabov

because this mixes two people and one institution at the same level.

## 4. Rules for tables and rankings

Any ranking or portfolio table must use columns in this order:

1. **Institution**
2. **Team / PI**
3. **Capability / mechanism**
4. **Evidence / differentiation**
5. **Decision state**

Examples:

### Correct
| Rank | Institution | Team | Capability | State |
|---|---|---|---|---|
| #1 | Kutateladze Institute | Pavlenko team | irreversible-dryout diagnostics | Stage-0 #1 |

### Not allowed
| Rank | Partner | State |
|---|---|---|
| #1 | Pavlenko | Stage-0 #1 |
| #2 | MPEI | Stage-0 #2 |

## 5. Rules for prose

First mention:
> **Kutateladze Institute of Thermophysics SB RAS — Pavlenko team**

Subsequent short mention in the same section may use:
> **Pavlenko team**

but only after the institution has already been established.

For MPEI:
> **Moscow Power Engineering Institute (MPEI) — Ivanov/Kuzma-Kichta team**

Do not write:
> Pavlenko, MPEI and Kabov are the three core partners.

Write:
> The current core work is concentrated in two main institutions: Kutateladze Institute (two distinct teams) and MPEI (one core team), with TPU as a Stage-0 challenger.

## 6. Strategic implication

The institution-first view changes how collaboration should be understood.

Current core structure:

### Institution A — Kutateladze Institute of Thermophysics SB RAS

Contains at least two distinct strategic research lines relevant to this project:

1. **Pavlenko team**
   - boiling crisis / irreversible dryout;
   - Stage-0 #1.

2. **Kabov / Chinnov team**
   - shear-driven films / instability / rupture;
   - High-risk Mechanism/IP Reserve.

This means one institution may support multiple collaboration hypotheses.

### Institution B — MPEI

Core team:
- Ivanov / Kuzma-Kichta / Alyautdinova;
- hierarchical surfaces / aging;
- Stage-0 #2.

### Institution C — TPU

Challenger team:
- Feoktistov / Orlova;
- process / wettability-pattern route;
- Stage-0 #3 Challenger.
