## Final output package

The project should ultimately produce four reading depths:

1. **Executive decision brief**
   - 10–15 page equivalent
   - for management / roadmap decision
   - what to do, what not to do, why, with whom, and next investment

2. **Full technical report**
   - complete evidence-to-decision narrative
   - problem -> baseline -> Russia capability -> gap -> transfer -> IP -> PoC -> roadmap

3. **Evidence appendix**
   - paper/patent/OEM/lab/ranking references
   - claim charts
   - source-quality and non-comparability notes
   - unresolved evidence gaps

4. **Presentation layer**
   - later derived from the approved executive/full report
   - not the source of truth

## Promotion rule

A direction may enter **Strategic Bets** only when it has:

- a real smartphone problem;
- current Russia capability evidence;
- strong China/global comparator;
- phone-transfer feasibility;
- falsification / kill criteria;
- IP/prior-art assessment;
- credible current partner;
- a concrete PoC;
- explicit unresolved risks;
- original-source traceability.

If one of these is missing, the direction stays:
- candidate;
- challenger;
- reserve;
- or unresolved.
