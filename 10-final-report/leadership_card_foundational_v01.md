# 1. Product problem

Two-phase thermal systems have large design spaces:
- geometry;
- heat flux;
- liquid inventory;
- gas shear;
- working fluid;
- wetting;
- transient hotspot;
- confinement.

Brute-force experiment/CFD can become expensive.

The product question is:

> Can an interpretable analytical/stability model locate the relevant failure boundary early enough to reduce our experiment matrix and expose the real controlling mechanism?

---

# 2. Why Russia / why this network

The retained Russia-side signal is not “Russia is better at mathematics.”

It is a more specific tradition:

- exact / group-invariant evaporative-convection solutions;
- thermocapillary two-layer models;
- linear/nonlinear stability thresholds;
- experiment-informed closure;
- current Lavrentyev microfilm modeling;
- historical and current linkage to Kutateladze film experiments.

Current capability architecture:

**ICM SB RAS / Altai**
→ exact / stability analysis

**Lavrentyev Institute**
→ detailed microfilm / microchannel fluid model

**Kutateladze**
→ mechanism experiment / diagnostics

**NSU**
→ talent / experimental execution

This is a **modular capability network**, not a confirmed integrated consortium.

# 3. Strongest China baseline

China is already strong in:

# 6. Phone-transfer gap

Current gaps:

- exact models rely on assumptions that may break in real phone geometry;
- no proof yet that model calibration cost is lower than CFD/experiment;
- no phone-specific reduced-order model has been demonstrated;
- current formal ICM ↔ Kutateladze collaboration status is not fully verified;
- current ICM ↔ Lavrentyev thermal collaboration is unverified;
- product packaging/manufacturing variables are outside many analytical models.

The danger is:

> an elegant model that is scientifically interpretable but does not reduce real engineering iterations.

# 7. Smallest discriminating PoC

## Blind failure-boundary benchmark

Use one locally heated confined thin-film / two-phase cell.

Freeze a 3–5 parameter space.

Before experiments:
1. Russian analytical/stability model predicts stable/unstable regions and boundary;
2. domestic numerical/data-driven baseline makes its own prediction.

Then:
3. physical experiment reveals wave/dry-spot/rupture onset;
4. compare prediction accuracy, calibration effort and experiment count.

Russian side:
- exact/reduced model;
- stability map;
- mechanism decomposition.

Our/China side:
- phone boundary conditions;
- high-fidelity reference model;
- experiment;
- independent scoring.

# 8. Success / Kill

## Internal blind-benchmark target

Promotion requires:

- **>=80% stable/unstable classification accuracy;**
- **<=15–20% failure-boundary error;**
- **>=50% experiment-grid reduction;**
- clearer mechanism attribution than the domestic numerical baseline.

These are **internal PoC targets**, not literature claims.

## Kill

Kill strategic use if:
- experiment count is not reduced;
- heavy empirical calibration is required;
- assumptions fail in the phone-relevant regime;
- boundary error is too large near the decision region;
- domestic method is equal/better at similar cost and interpretability.
