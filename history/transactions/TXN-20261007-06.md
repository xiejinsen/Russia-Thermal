# TXN-20261007-06 — Dense Capability and Institution Explorers

state: CLOSED
date: 2026-10-07
purpose: replace vertically expensive Capability and Institution card grids with text-rich full-width dense row explorers.

User-observed problem:
- Capability and Institution collections have grown large;
- card grids consume too much vertical space;
- unlike Papers/Claims, these objects contain too much explanatory text for a rigid spreadsheet row.

Implemented:
- reusable `DenseObjectRow.astro` shell;
- Capabilities converted from card grid to full-width horizontal dense rows;
- Institutions / Labs converted from card grid to full-width horizontal dense rows;
- both pages now use compact single-line sticky Explorer filters;
- Capability rows retain statement, owner, key people, strategic use, transfer boundary, maturity/evidence/fit, technical scope and Direction context;
- Institution rows retain hierarchy, location, summary, key people, capability/people counts, portfolio disposition and Direction context;
- row-level Claims / Papers / Evidence navigation retained where relevant;
- responsive layout collapses from four semantic zones to two, then one, rather than forcing a wide spreadsheet.

Design rule added:
- Papers / Claims / Evidence -> dense tables;
- Capabilities / Institutions -> dense row explorers;
- Directions / Priorities -> strategic cards / compact registries.
