# TXN-20261007-20 — Detail Page Design System Pilot

state: CLOSED
date: 2026-10-07

## Purpose

Convert the audited research graph into decision-readable detail pages without duplicating research semantics in the UI layer.

## Pilots

- Institution: ACT-KUT-LAB13
- Direction: DIR-FAILURE-AWARE-UTVC

## Shared components added

- web/src/components/detail/DetailHero.astro
- web/src/components/detail/MetricStrip.astro
- web/src/components/detail/EvidencePressure.astro
- web/src/components/detail/RelationPath.astro

## Institution detail changes

Institution detail now exposes:
- why-it-matters summary;
- compact Capability / Scholar / Evidence / Deep Read metrics;
- local Institution -> Scholar -> Capability -> Claim -> Evidence -> Direction graph path;
- hierarchy and formal collaborating actors;
- Evidence Pressure;
- dense People / Capability / Claim / Evidence / Direction rows.

The prior card-grid detail composition is removed.

## Direction detail changes

Direction detail now exposes:
- investment lane and maturity/confidence;
- audited Evidence Pressure;
- Problem / China-global baseline / Russia residual / internal-control boundary;
- Next question / Promotion gate / Kill-downgrade gate;
- Institutions / scholars / capabilities;
- Claims and primary evidence with Deep Read depth;
- decision history.

Direction evidence metrics now use the same closure rule as tools/graph_audit.py:
direct Direction Claims + candidate-Capability Claims -> Sources.

This removes the previous web-only undercount.

## Data / VM changes

- InstitutionPageVM now includes Claims, Evidence, collaborators and evidence-pressure metrics.
- DirectionPageVM now includes audited evidence-pressure metrics.
- Evidence rows expose Deep Read level / review state.
- Direction card VM exposes Kill/downgrade gate.

## Architecture rule

Detail pages share visual primitives but retain object-specific view models and composition.
Do not create a universal mega-template.
