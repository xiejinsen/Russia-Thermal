Implemented:

## Semantic Dense Row variants

`DenseObjectRow.astro` now supports:
- `content-heavy`
- `detail-heavy`
- `balanced`

Assignments:
- Papers -> detail-heavy
- Evidence -> detail-heavy
- Claims -> content-heavy
- Capabilities -> content-heavy
- Research Coverage capability rows -> content-heavy
- Institutions -> balanced
- Scholars -> balanced

The shared interaction pattern remains consistent while geometry changes according to object semantics.

## Scholars

Scholars / key people converted from card grid to full-width Dense Row Explorer.

Each row retains:
- person identity / country / priority / status;
- affiliation and role;
- research relevance;
- capability touchpoints;
- capability / Direction counts;
- portfolio disposition;
- Direction context;
- Claims / Papers / Evidence relationship actions;
- Scholar detail drill-down.

The existing filters remain:
- Country;
- Affiliation;
- Research role;
- Direction;
- full-text search.

Toolbar now uses the compact sticky one-line mode.

## Design rule

Dense Row is a shared interaction model, not a universal fixed four-column geometry.

Use semantic weighting:
- content-heavy when the proposition / capability statement is the dominant reading object;
- detail-heavy when findings / boundaries should receive more width than identity;
- balanced when identity and explanatory context matter similarly.
