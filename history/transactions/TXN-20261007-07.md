# TXN-20261007-07 — Unified Semantic Dense Row Explorers

state: CLOSED
date: 2026-10-07
purpose: replace rigid spreadsheet tables for Papers / Claims / Evidence with the same semantic full-width Dense Row Explorer pattern validated on Capabilities / Institutions.

User feedback:
- the full-width Dense Row Explorer is easier to scan and understand than rigid tables;
- Paper / Claim / Evidence records also benefit from more semantic text per item;
- high density should not require squeezing meaning into narrow columns.

Implemented:

## Papers
Each row now preserves:
- Paper ID / year / country;
- title / authors / venue;
- first direct finding;
- source boundary;
- Claim / Direction counts;
- Deep Read state / review basis;
- Direction context;
- direct Paper detail and Original-source actions.

Paper search now includes direct findings and boundary.

## Claims
Each row now preserves:
- Claim ID / status / confidence;
- proposition;
- boundary;
- decision role;
- support / pressure counts;
- linked Capability count;
- Direction context;
- direct Support / Pressure Evidence and Paper relationship actions.

Claim search now includes supporting / contradicting Source IDs, enabling a Paper ID to locate Claims that consume that Paper.

## Evidence
Each row now preserves:
- Source ID / type / year / country;
- title / citation context;
- first direct finding;
- boundary;
- usage role;
- support / pressure / Capability counts;
- Direction context;
- direct Original-source action;
- concrete linked Capability drill-down.

Paper Evidence continues to open Paper detail; non-Paper Evidence keeps its original-source path.

## Shared behavior retained
- compact single-line sticky filter toolbar;
- URL-driven visible filters and hidden relationship scopes;
- full-text search;
- visible result count;
- responsive 4-zone -> 2-zone -> 1-zone row layout;
- object detail and relationship drill-down.

## Design principle

Production high-cardinality research collections now use semantic Dense Row Explorers:
- Papers;
- Claims;
- Evidence;
- Capabilities;
- Institutions.

Directions / Priorities and other low-cardinality decision objects remain strategic cards / compact registries.

The rigid DenseResearchTable remains available as a component but is no longer the default production pattern for these research collections.
