# TXN-20261007-21 — Scholar / Paper / Patent Detail Functional Closure

state: CLOSED
date: 2026-10-07

## Purpose

Extend the frozen Detail Page Design System from Institution/Direction to the remaining evidence-navigation layers without additional visual-design iteration.

## Scholar Detail

Scholar pages now expose:
- canonical affiliation and formal capability collaborators;
- capability contexts and linked Directions;
- full Claim set reachable through scholar-linked Capabilities;
- Evidence Pressure metrics;
- linked evidence with Deep Read depth;
- direct-authored evidence separated from comparator / capability-linked evidence.

The authored-evidence distinction prevents China/global comparator sources from being misrepresented as the scholar's own output.

Pilot:
- PERSON-PAVLENKO

## Paper Detail

Paper detail retains the existing technical structure but now uses the shared TechnicalDeepRead component.

The Q1-Q10 Deep Read continues to expose:
- why the paper matters;
- review basis;
- decision use;
- source facts;
- analyst inference;
- unknown/request;
- Claim / Capability / Direction / Priority graph impact.

## Patent Detail

Added:
- /patents/[id]
- buildPatentPageVM
- patentIds
- PatentPageVM

Patent detail exposes:
- public patent identity;
- inventor list;
- claim-reviewed scope;
- legal / technical boundary;
- P1-P10 Deep Read;
- supporting and pressure Claims;
- connected Capabilities / Directions / institutions / scholars.

Patent inventors are now normalized from canonical Inventors fields into the shared source-author field.

## Shared Deep Read component

Added:
- web/src/components/TechnicalDeepRead.astro

This component handles:
- Paper Q1-Q10;
- Patent P1-P10;
- Evidence Boundary;
- graph-impact links.

Paper and Patent evidence therefore use one normalized interpretation layer.

## Navigation closure

Local Patent detail links are now available from:
- Evidence Explorer;
- Institution detail;
- Direction detail;
- Scholar detail.
