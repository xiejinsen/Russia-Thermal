# TXN-20261007-27 — Web Usability and Readability Pass

state: CLOSED
date: 2026-10-07

## Trigger

User review of the live Phase-1 web report identified four concrete usability issues:

- the primary navigation was too tall;
- the four Overview entry actions used inconsistent visual treatment and awkward arrow glyphs;
- Audit/detail copy was too small and too gray for shared-screen review;
- long information cards used whole-card links, making text selection and copying difficult.

The follow-up pass expanded these findings into a low-risk site-wide usability audit.

## Design rules applied

1. **Content first, metadata second**
   - decision-relevant prose should remain readable on a shared screen;
   - secondary labels may stay compact, but explanatory text should not depend on very small gray type.

2. **Containers carry information; explicit controls carry navigation**
   - long cards and comparison cells should remain selectable/copyable;
   - titles and explicit action links provide navigation.

3. **Research tooling should feel approachable**
   - dense explorer controls remain compact but receive larger control text and clearer spacing;
   - visual hierarchy is retained without making the interface feel like an internal admin console.

## Main changes

- reduced desktop primary-header height by roughly one third;
- unified the four Overview entry actions and removed decorative arrow glyphs;
- increased Audit Evidence / Papers / Claims detail copy size, weight and contrast;
- removed whole-card navigation from Direction cards;
- removed remaining whole-block links from Overview management, comparison and reject surfaces;
- converted Russia / China matrix cells to explicit research-map actions;
- improved readability across Institution, Scholar and Capability explorers;
- enlarged compact Explorer toolbar controls and corrected its sticky offset after header reduction;
- improved Evidence Pressure, Detail Hero, Evidence Chain and Metric annotation readability;
- increased map-node, map-detail and coverage-gap explanatory text for both Russia and China research maps;
- improved key Overview body copy for shared-screen review.

## Research semantics

No canonical research conclusion, Claim, Source, Direction, partner disposition or evidence relationship was changed.

## Validation

- V2.1 Repository Health: PASS on final main head;
- source-level checks confirm explicit-link interaction model on updated Overview / Direction / matrix surfaces;
- Web UI Check / deployment continue through the repository's normal GitHub Actions pipeline.

## Closure

This pass is closed as the first user-feedback-driven usability pass.

Future visual changes should continue to prioritize:
- legibility at presentation/share-screen distance;
- predictable explicit navigation;
- selectable research text;
- approachable, human-facing information design.
