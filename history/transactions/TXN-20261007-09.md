# TXN-20261007-09 — Dense Row Visual Rebalance

state: CLOSED
date: 2026-10-07
purpose: reduce unused horizontal whitespace in Dense Row Explorers by allocating width according to semantic weight and compacting action controls.

User-observed problem:
- Dense rows still behaved too much like four equal columns;
- the primary content column wrapped heavily while short transfer-boundary / metadata regions occupied too much width;
- horizontal action strips consumed width despite containing only a few compact navigation controls.

Implemented in the shared `DenseObjectRow.astro`:
- primary content widened substantially;
- explanatory-detail column narrowed;
- metadata column narrowed;
- Actions converted to a fixed narrow rail;
- action controls use a 2-column grid;
- page-level `row-actions` wrappers collapse with `display: contents`, so the auto-generated Open action joins the same grid;
- four actions naturally render as 2×2;
- fewer actions use the same compact grid;
- subtle vertical separators added between semantic zones;
- responsive breakpoint moved so the four-zone layout collapses to 2×2 before becoming too cramped;
- narrow-screen layout remains single-column with separators removed.

The shared change applies to:
- Research Coverage;
- Capabilities;
- Institutions;
- Papers;
- Claims;
- Evidence.

Design rule added:
space follows semantic weight; primary content receives the largest share, while action controls must remain visually subordinate.
