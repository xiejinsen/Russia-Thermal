# TXN-20261008-03 — Source Deduplication Governance

state: CLOSED
date: 2026-10-08

## Trigger

Before continuing Capability Atlas research, the user required a repository-level mechanism to prevent the same paper, patent or other Source from being added multiple times through different discovery/database routes.

## Existing protection

The repository already rejected exact duplicate raw `source_key` values.

This was insufficient for:
- DOI formatting variants;
- DOI resolver vs publisher/database URLs;
- exact patent publication discovered through different patent databases;
- HTTP/HTTPS/tracking variants of the same official page;
- same Paper entering under slightly different title formatting.

## New mechanism

Added:
- `00-project/source-deduplication-contract.md`;
- normalized Source identity fingerprints in `tools/v2repo.py`;
- fuzzy title/year/author review warnings;
- `tools/source_dedup.py` candidate preflight;
- CI dedup scan;
- `00-project/source-aliases.md` for deprecated IDs after merges.

Hard failures now cover:
- duplicate normalized DOI;
- duplicate normalized patent publication number;
- duplicate canonical URL identity;
- exact normalized Paper title + publication year.

Fuzzy matches remain warnings and require review rather than automatic deletion.

## Real duplicate found immediately

The new mechanism detected:

- `OFFICIAL-MPEI-IVANOV-001`
- `OFFICIAL-MPEI-SIC-MICROCHANNEL-001`

Both represented the same underlying MPEI webpage.

Resolution:
- kept `OFFICIAL-MPEI-IVANOV-001` as canonical;
- merged both sets of direct facts into that Source;
- preserved the distinct Ivanov and SiC-microchannel Claims;
- repointed current canonical Claim references;
- removed the duplicate Source object;
- recorded the retired ID in `00-project/source-aliases.md`;
- historical transaction files were not rewritten.

## Governance rule

Search results and database landing pages are discovery artifacts, not new Sources.

The workflow is now:
stable identity -> preflight -> existing Source reuse or new Source -> Claim linkage.

## QA

After the real duplicate was merged:
- V2.1 Repository Health returned PASS;
- no Source dedup review warnings remained in the baseline corpus.

No strategic Direction or collaboration decision changed.
