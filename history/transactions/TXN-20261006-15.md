Core architecture:
canonical objects
-> adapters
-> normalized data
-> view models
-> components
-> pages
-> isolated interactive islands

Key governance:
- web is derived, never canonical;
- no page/component reads raw canonical Markdown;
- no component performs strategic inference;
- design values use tokens;
- page logic uses view models;
- routine changes should remain blast-radius Level 0-1;
- interactive features are isolated;
- image provenance and accessibility are first-class constraints.

Framework direction:
Astro static-first MVP, with optional React only inside specific interactive islands.

DESIGN ONLY. No frontend code started.
