## Current benchmark state

China/global public evidence is already strong in:
- sub-0.4 mm UTVC;
- composite / wettability-enhanced wick structures;
- mobile ultra-thin/flexible LHP;
- active fan cooling;
- micropump/liquid cooling;
- graphite/TIM/material systems;
- microfluidics;
- adaptive runtime/DVFS;
- recent vapor-chamber OEM patent integration.

For the current Tier-A surface/wick route, the benchmark includes:
- 0.35 mm UTVC;
- 0.39 mm sealed composite-wick UTVC;
- 0.4 mm wettability-patterned UTVC;
- laser-modified wick;
- recent Huawei/Xiaomi/Honor capillary-structure patents.

## Rule

This is not a country ranking.

A Russian capability advances only if it offers:
- complementarity;
- a measurable frontier shift;
- difficult-to-reproduce mechanism/know-how;
- or a clean joint system-level control point.

## Main evidence gaps

1. independent teardown and measured OEM cooling results;
2. current flagship internal thermal-stack geometry;
3. more OEM/supply-chain patent depth outside the current surface/wick set;
4. installed active-cooling power/noise/reliability measurements.

## Stage-0 comparator freeze

Research date: 2026-10-04

The new Russian blocker-closure evidence does **not** lower the China/global benchmark.

For Stage-0 partner scoring, continue to use:
- ~0.39–0.4 mm sealed UTVC;
- ~0.2 mm internal channel;
- ~60 μm mesh-class reference;
- DI-water copper-VC product path;
- wettability-patterned/composite/laser-modified UTVC as strong comparators.

Canonical cross-country decision:
../09_collaboration-roadmap/stage0_partner_technology_decision_scorecard_v01.md

Therefore:
a Russia candidate can advance only by demonstrating a **specific mechanism gap** (dryout/rewet, long-life scaled hierarchy, or sealed-process-stable wetting control), not by reproducing generic modern UTVC technology.
