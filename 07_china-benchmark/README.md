# 07 — China Benchmark & Russia–China Capability Gap

## Goal
Compare Russian capabilities with Chinese academic, industrial, manufacturing and product-integration strengths using the same technical dimensions.

## Current outputs
- [China mobile thermal baseline v0.1](china_mobile_baseline_v01.md)
- [China institution / lab map v0.1](institution_map_v01.md)

## Comparison dimensions
- fundamental mechanisms
- experimental facilities
- two-phase / capillary structures
- active cooling
- aeroacoustics
- materials
- control/software
- miniaturization
- manufacturing / supply chain
- smartphone integration
- patents / IP
- evidence of productization

## Rule
The purpose is not an overall country ranking. The output should identify **complementarity, duplication and whitespace**.

## Current status
Active. Institution-level benchmark now includes:
- Xi'an Jiaotong University
- Huazhong University of Science and Technology
- South China University of Technology
- Shanghai Jiao Tong University
- Peking University
- Beihang University
- first mobile-runtime/DVFS seed at USTC

The benchmark is now strong enough to reject broad claims such as “Russia has LHP/aeroacoustics, therefore it has an advantage.” Each candidate must be compared on a narrower mechanism, metric and mobile-transfer condition.
