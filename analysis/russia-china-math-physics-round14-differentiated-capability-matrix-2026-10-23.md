# 第十四轮｜俄罗斯差异化能力候选矩阵与端侧迁移门槛（2026-10-23）

**状态：** EVIDENCE-MATRIX-DRAFTED / TEAM-LEVEL-METHOD-CANDIDATES / CHINA-COUNTEREXAMPLES-RETAINED / PHONE-TRANSFER-UNPROVEN

## 0. 本轮范围与重要边界

本轮承接第十三轮的近期数学物理研究审计，将已有证据收敛为“能力候选矩阵”，用于决定下一轮补什么证据、哪些判断可用于内部技术讨论，以及哪些暂时不能转化为手机热管理技术路线建议。

本轮**不声称完成新一轮全面联网检索**：本次外部搜索额度不可用，因此只综合仓库中已有的原刊/官方来源记录和既有审计结果。没有重新访问或逐式审读的内容仍保留原证据等级；不会把摘要级证据升级为全文级，也不会把未命中写成不存在。

项目终极目标仍是：评估俄罗斯特定高校/研究机构在热物理、数学物理与建模方面是否存在可验证的差异化能力，判断哪些能力值得与中国团队对照或合作，以及是否可能对智能手机封闭式均热板（VC）、吸液芯和瞬态热管理形成可迁移价值。不是为国家排名而排名，也不是预设新的技术方向。

## 2. 当前最稳健的核心结论

### 2.1 可以用于内部讨论的结论

1. **俄罗斯侧值得进一步验证的候选优势不是“数学更强”，而是部分研究线在特定相变液膜问题上持续组合使用显式相变边界、气相传输、基态构造与谱稳定性/瞬态演化分析。**
2. **中国侧也存在扎实的数学物理研究。** 宁波大学的临界模态、扰动能量机制与非模态放大，以及中国 2024 年三维蒸发/冷凝长波模型，足以否定“俄罗斯理论、中国工程”的简单二分。
3. **研究线连续性已经有证据，但研究连续性不是模型预测更准确的证据。** ITP 2017 低热流偏差和 RU24/RU25 尚未完成的公式级核验必须继续保留。
4. **高校数学声誉/数学排名只能作为外围背景变量。** 它不能替代具体团队在目标物理问题上的方程、验证和复现证据。
5. **手机 VC/吸液芯的迁移价值尚未证明。** 自由表面蒸发液膜、液氮淬冷、海水降膜蒸发与封闭式均热板/多孔吸液芯具有不同边界条件、工质、尺度与主导机制。

### 2.2 当前不能声称的结论

- 俄罗斯国家整体数学物理能力高于中国；
- Prokudina 2024/2025 已被证实是两项独立理论突破；
- ITP 2017 模型比 2014 更准确；
- 俄方谱稳定性方法已经提高手机 VC 的 Qmax、降低热阻或更准确预测局部干涸；
- 在当前检索样本中没有找到完全同题中国论文，就代表中国不存在此类研究。

## 3. 工程迁移门槛：先定义同条件预测契约

在推荐合作或将方法纳入手机热管理路线之前，至少要有以下可复核契约。

### 3.1 候选任务（不是已经选定的新技术方向）

优先测试的不是把液膜方程直接移植到 VC，而是更抽象的建模能力：
- 瞬态热输入下的局部温度/热通量响应；
- 两相/界面过程对状态变化的影响；
- 失稳、干涸或性能突降的临界条件；
- 模型对边界条件、物性和几何参数的敏感性；
- 简化模型相对 CFD/实验基准的精度—成本折中。

### 3.2 必须统一的比较项

| 字段 | 规定 |
|---|---|
| 物理装置 | 明确是自由液膜、蒸发器、封闭 VC，还是多孔吸液芯；不同装置不得直接混排名 |
| 输入与边界 | 相同热功率/热流、冷端条件、工质物性、几何、姿态和初始状态 |
| 预测输出 | 预先选定温度、热阻、Qmax、干涸阈值、最小膜厚或失稳时间；不得事后挑指标 |
| 参考真值 | 实验/可信基准数据及测量不确定度；用户当前无真机，首阶段可用公开实验数据或文献基准 |
| 误差 | 预先约定 MAE/RMSE/MAPE 或阈值偏差；给出定义、单位、数据覆盖范围 |
| 独立性 | 分开训练/校准数据与验证数据，标注重合与否 |
| 计算成本 | CPU 时间、内存、收敛性、模型复杂度；最终需考虑端侧算力与功耗 |
| 失效边界 | 何种工况会偏离、失稳、干涸或失去物理适用性 |
| 可复现性 | 公式、参数、代码或足以重建的算法说明 |

### 3.3 升级决策的门槛

- **从研究线索升级为方法优势：** 必须有全文级推导、清楚的新增贡献及近邻方法比较。
- **从方法优势升级为预测优势：** 必须在相同输入/边界和独立参考数据上获得可复核的误差/阈值增益。
- **从预测优势升级为端侧技术价值：** 必须证明机制与 VC/吸液芯相符，并在目标工况/可信实验基准上改善预测或设计决策。
- **从端侧技术价值升级为项目优先级：** 还需成本、功耗、实现复杂度和可合作性证据。

## 4. 下一轮的优先级

### P0 — 先完成俄方 RU24/RU25 全文公式核验
- RU24：逐页核对四阶 PDE、无量纲参数、初边值条件、离散格式、稳定性/收敛与临界 Marangoni 数。
- RU25：核对包络方程、系数如何从增长率/频率导数得到、窄带假设与非线性闭合。
- 生成“共享前提—不同状态变量—不同输出—真正新增贡献”逐项表。若无法取得可读 PDF，明确记为阻塞，不以摘要替代全文审计。

### P1 — 补齐中国近期同题近邻和全球方法谱系
- 重点追踪中国 2021–2026 年“显式气相输运 + 相变界面 + 基态/谱稳定性”研究。
- 记录数据库、查询式、纳入/排除标准与未命中范围；中国 2024 三维蒸发/冷凝长波模型作为已知近邻。
- 全球挥发液膜稳定性研究单独标记 GLOBAL，避免把国际共同方法归为俄罗斯独占。

### P2 — 形成可复现 benchmark 设计
- 选一个可公开获得实验基准的输出（优先温度瞬态、临界阈值或液膜破裂时间中可获得数据者）。
- 先定义输入、边界、指标、参考不确定性和计算成本；再比较模型，而不是先挑看起来对某一方有利的指标。
- 因用户无真机，不把设备实测设为当前启动条件；可先用公开文献数据做基线，但最终工程迁移仍需目标装置验证。

### 决策状态
- **基础数学建模：RESERVE**（仅作为研究储备，不建议直接立项）。
- **P1/P2/HOLD：保持现有状态，不因本轮矩阵改变。**
- **国家整体优劣：NOT ESTABLISHED。**
- **俄罗斯特定方法组合：WORTH FURTHER TESTING，非已证实独占优势。**
- **端侧迁移：UNPROVEN。**
