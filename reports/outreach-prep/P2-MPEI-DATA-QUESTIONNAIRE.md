## 1. Internal objective

Determine whether MPEI's 42-month long-duration evidence contains enough time-resolved / discriminating information to justify a collaboration.

If the answer is "only the final published endpoint is available", the package remains a literature reserve and no active project should be opened.

## 2. One-sentence framing

We are interested in whether long-duration capillary / surface-state evolution provides an earlier or different degradation signal than oxidation chemistry, process QA and standard thermal metrics.

## 3. Data availability questionnaire

### A. Operation history

1. Was the system monitored continuously, periodically or only at beginning/end?
2. What operating periods and shutdown intervals are known?
3. Are heat load, temperatures, pressure, flow or other operating channels archived?
4. Were there maintenance, refill, cleaning, contamination or component-replacement events?
5. Are environmental conditions / storage periods documented?

### B. Capillary / surface state

6. Were capillary imbibition or wickability measurements made before operation?
7. Were any intermediate measurements made during the 42-month period?
8. What post-operation capillary / wetting measurements exist?
9. Are contact angle, morphology, roughness or chemical-composition measurements available?
10. Can surface-state changes be linked to specific operating periods?

### C. Repeatability

11. How many nominally comparable samples / devices were tested?
12. Were control samples retained?
13. Was the degradation behavior observed in more than one sample?
14. Are measurement uncertainties available?

### D. Thermal behavior

15. Which thermal-performance metrics were tracked over time?
16. At what interval?
17. Is raw temperature / heat-load history available?
18. Can the time at which capillary degradation began be compared with thermal-performance changes?

### E. Materials / process

19. Exact substrate and surface/coating process?
20. Working fluid and fill condition?
21. Groove / wick geometry?
22. Which fabrication steps were performed by MPEI?
23. Which were performed by Newfrost?
24. Are there process lots / sample IDs linking fabrication to performance?

### F. Phone-relevant reproduction

25. Can the relevant surface/process be applied to copper?
26. Can the team work with a sealed copper-water structure?
27. What is the smallest realistic feature/device scale?
28. Can accelerated and calendar-aging tests be run on the same material/process family?
29. Can post-mortem capillary / chemistry analysis be repeated after a controlled phone-relevant exposure?

### G. Data / IP

30. Which raw data can be shared?
31. Can sample-level metadata be shared?
32. Can derived degradation features be used in an internal model?
33. Are Newfrost rights involved?
34. Are there publication / patent restrictions?

## 4. Minimum evidence required to open a collaboration

At least one of the following must be true:

### Path A — historical data
Time-resolved or repeated-state data permit a precursor analysis.

### Path B — repeatability
Multiple samples demonstrate a reproducible long-duration capillary-state shift.

### Path C — transfer experiment
A copper-water / phone-relevant reproduction can be designed without importing an irrelevant large-thermosyphon architecture.

If none are true:
**do not open an active collaboration.**

## 5. Internal analysis plan if data are available

Domestic/product baseline:
- oxidation / oxygen state;
- process QA;
- standard thermal resistance;
- accelerated-aging exposure.

Candidate MPEI variables:
- imbibition / wickability;
- wetting state;
- morphology;
- other long-duration capillary-state metrics.

Question:

> Do the MPEI variables explain future transport-margin loss or degradation earlier/better than the product baseline?

## 6. Promotion criteria

Move beyond Reserve only if:

- data are sufficiently discriminating;
- a precursor or distinct degradation mode is reproducible;
- incremental value survives adjustment for chemistry/process/thermal metrics;
- phone-relevant transfer is credible.

## 7. Stop criteria

Stop if:

- only final endpoint data exist;
- there is no repeatability;
- chemistry/process metrics fully explain the degradation;
- no copper-water reproduction path exists;
- data/IP restrictions prevent falsification.
