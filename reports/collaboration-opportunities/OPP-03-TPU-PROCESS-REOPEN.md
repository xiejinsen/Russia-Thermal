## 1. Management decision

This is **not an active collaboration opportunity**.

TPU remains recorded because its process execution is credible, but public evidence no longer supports a concept-level smartphone differentiation.

China already demonstrates:

- laser-modified UTVC wicks;
- oxidation / corrosion / laser treatment comparisons;
- 0.39 mm integrated UTVC geometry;
- 0.4 mm wettability-patterned UTVCs;
- biphilic / self-driven VC patent prior art;
- hierarchical laser-wick patent prior art.

Therefore generic laser, biphilic or spatial wettability patterning is not a reason to engage.

## 2. What would justify reopening

Reopen only if TPU can show a **process-specific increment** under matched phone-relevant conditions.

Candidate increments could include:

- materially lower outgassing;
- better vacuum-bake retention;
- better sealed-fluid chemical compatibility;
- higher process durability;
- superior transient rewetting under identical geometry;
- higher manufacturing yield;
- a diagnostic or metrology capability unavailable domestically.

This list is a set of hypotheses, not current claims.

## 3. Required matched baseline

Any future TPU result must be compared with a strong domestic target-system control, not an untreated coupon.

Minimum control set should include as appropriate:

- current domestic laser-treated wick;
- thermal oxidation / chemical treatment;
- uniform hydrophilic control;
- current wettability-patterned UTVC control;
- same copper thickness;
- same fluid;
- same sealed process;
- same footprint / fill ratio / orientation.

## 4. Required process evidence

Before reopening, request evidence on:

- substrate and copper thickness;
- feature height / roughness / pattern dimensions;
- process repeatability;
- surface chemistry;
- vacuum / bake behavior;
- outgassing / contamination;
- DI-water or target-fluid compatibility;
- post-seal wettability retention;
- cycling / aging;
- manufacturing yield;
- transient rewetting or dryout recovery under confinement.

Open-surface droplet durability alone is insufficient.

## 5. Reopen gate

Reopen to a bounded Stage-0 Challenger only if a matched comparison shows:

- a process-specific advantage not already represented by China/domestic target-system controls;
- compatibility with sub-0.4 mm sealed-device constraints;
- acceptable contamination / outgassing / vacuum behavior;
- repeatability across samples;
- a plausible path to measurable phone-system value.

## 6. Hold / kill gate

Remain HOLD or move to reference-only if:

- evidence remains open-surface;
- performance benefit disappears after matched controls;
- advantage requires extra feature height incompatible with the device;
- chemistry or contamination risk is unacceptable;
- no system-level value survives.

## 7. What we must keep internally

Even after reopening:

- phone VC architecture;
- thin-copper geometry;
- fluid / sealing process;
- final pattern specification;
- product validation;
- foreground IP

remain internally controlled.

## 8. First contact rule

There is **no proactive outreach action** today.

If a future public result or external introduction suggests the reopen gate may be met, first ask only:

1. Can TPU process phone-relevant thin copper?
2. What is the actual feature-height / process window?
3. What vacuum / outgassing / fluid-compatibility data exist?
4. Is there sealed-device transient rewetting or dryout-recovery data?
5. Can they run a matched baseline rather than compare against untreated copper?

Only positive answers justify a technical discussion.
