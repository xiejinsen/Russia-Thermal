Title:
A methodology to predict the power dissipation limits of high-heat-flux vapor chambers considering boiling in the evaporator

Direct reported results:
- physics-based vapor-chamber model couples temperature fields with wick/vapor-core transport;
- boiling region is identified from wall superheat;
- two-phase wick hydrodynamics are modeled using relative permeability;
- neglecting two-phase boiling hydrodynamics can substantially overpredict dryout limit.

Boundary:
larger high-heat-flux VC case, not phone-scale online observer. Supports the need for hidden transport-state modeling when interpreting thermal observables near dryout.
