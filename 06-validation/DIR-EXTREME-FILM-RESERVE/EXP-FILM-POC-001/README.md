dry-spot onset; rupture/recovery; thermal resistance; gas/liquid flow; pressure drop; total actuator power; acoustic output; package volume.

Pass/Narrow:
stable operation plus repeatable failure-boundary prediction and system value beyond strong controls.

Fail:
parasitic power, noise, volume or instability overwhelms thermal value.

Boundary:
no physical result exists; experiment is deferred.
