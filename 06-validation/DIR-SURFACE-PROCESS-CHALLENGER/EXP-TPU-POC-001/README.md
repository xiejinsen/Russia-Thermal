# EXP-TPU-POC-001

record_state: CURRENT
direction_id: DIR-SURFACE-PROCESS-CHALLENGER
validation_type: PHYSICAL_POC
state: DEFERRED

Question:
Does a TPU-derived laser-only or wettability-contrast copper surface survive DI-water/vacuum/process exposure and improve confined liquid routing / rewetting versus a strong generic reference?

Baseline:
strong conventional oxidation / laser-hydrophilic or current UTVC laser-treated-wick reference.

Measurements:
feature height; pattern fidelity; wetting-state retention; mass/outgassing proxy; capillary directionality; redistribution/rewetting time; dryout limit; thermal resistance; post-process stability.

Pass/Narrow:
phone-compatible, process-stable state plus incremental confined rewetting/dryout value.

Fail:
contamination/outgassing risk, wetting-state collapse, geometry failure, or no advantage over strong generic reference.

Boundary:
no physical result exists; experiment is deferred.
