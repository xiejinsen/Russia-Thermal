# EXP-MPEI-POC-001

record_state: CURRENT
direction_id: DIR-HEALTH-AWARE-UTVC
validation_type: PHYSICAL_POC
state: DEFERRED

Question:
Does a scaled MPEI hierarchy retain useful liquid-supply behavior, and does capillary-state drift correlate with future dryout-margin degradation before nominal thermal resistance changes materially?

Baseline:
strong domestic copper-water thin-wick / oxidation-process reliability control.

Measurements:
geometry; coating thickness; capillary uptake; permeability; wetting state; high-flux dryout margin; thermal resistance; vacuum/process/cycle retention.

Pass/Narrow:
phone-compatible geometry plus a repeatable capillary/health signal that adds information beyond strong baseline reliability metrics.

Fail:
geometry cannot scale, high-flux benefit disappears, process is unstable, or no incremental early health signal emerges.

Boundary:
no physical result exists; experiment is deferred.
