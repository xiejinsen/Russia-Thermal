# Russia-Thermal V2.1 Methodology

## Canonical reasoning chain

SOURCE -> CLAIM -> ACTOR / CAPABILITY -> DIRECTION -> VALIDATION / EXPERIMENT -> DECISION_EVENT -> GENERATED VIEW / REPORT

## Research workflow

Decision goal -> primary evidence -> mechanism -> comparator pressure test -> capability assessment -> narrow strategic hypothesis -> smallest discriminating validation -> Keep / Narrow / Kill / Watch / Hold.

## Evidence discipline

Distinguish:
- source fact;
- analyst synthesis;
- hypothesis;
- negative evidence / search absence.

Never transform:
- not publicly evidenced -> does not exist;
- no matched public comparator recovered -> competitor lacks capability;
- paper -> product;
- patent -> deployment;
- collaboration precedent -> product adoption;
- historical lineage -> current institutional project.

## Phase-1 validation boundary

Current project constraints do not allow real phone experiments or routine direct university outreach.

Therefore physical/product validation objects can remain DEFERRED.
Low product-validation maturity does not erase a valid capability insight.

## Deep-reading method

Decision-critical papers/patents may use the project 10Q method:
problem / novelty / hypothesis / lineage / mechanism / experiment / data / evidence-vs-inference / decision contribution / next action.
