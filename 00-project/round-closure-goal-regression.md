# Round-Closure Goal Regression Checkpoint

status: REQUIRED
date: 2026-10-08
scope: all future Russia-Thermal research rounds

## Purpose

Prevent multi-round research drift and make drift visible early.

Every meaningful research round must end with a compact project-goal regression before the round is considered closed.

## Fixed project goal

Build an evidence-based map of Russian organizations, teams and researchers with capabilities relevant to mobile-terminal thermal management, then determine:

1. what Russia can actually do in this field;
2. which Russian capabilities can transfer to smartphones, tablets, wearables and adjacent compact electronics;
3. which Russian teams may be useful collaboration partners;
4. where China already has equivalent or stronger capability, so leadership can answer "why not do this in China?";
5. which Russia-side residual strengths still justify selective collaboration;
6. whether any collaboration could support long-term internal capability/team building.

The project is not required to prove that Russia is broadly better than China.

## Scope guardrails

- Hardware thermal management is primary.
- Enabling mechanism / diagnostics / reliability / modeling is in scope when transfer-relevant.
- Software/system thermal management remains LIMITED_SCAN.
- Public literature, patents, official sources and other open evidence are the decision basis.
- Lack of public evidence must not be stated as proof of absence.
- No experimental/device-testing requirement is assumed for the current insight phase.
- Institution prestige is context, not proof of technical superiority or collaboration value.

## Mandatory round-close review

Each round summary must report:

### A. Final questions
For each final question above:
- current answer / working conclusion;
- status: NOT_STARTED / IN_PROGRESS / SUBSTANTIALLY_ANSWERED / CLOSED;
- important remaining gap.

### B. Workstream progress
At minimum:
- Russia Capability Atlas;
- Russia Institution / People Atlas;
- platform-transfer assessment;
- relevant papers / patents / source provenance;
- collaboration / industry / international links;
- Russia-vs-China comparison;
- collaboration portfolio / priorities;
- leadership-facing web/report readiness.

### C. Drift check
Explicitly answer:
- Did this round still support the original leadership decision?
- Did we over-focus on one mechanism/institution?
- Did we mistake ranking/publication count for capability?
- Did we mistake public-evidence gaps for absence?
- Did we accidentally reopen closed Phase-1 work without a trigger?

### D. Current corpus / SSOT state
Report key object counts and repository health state.

### E. Next smallest useful step
State the next bounded research task and why it closes a remaining final-question gap.

## Closure rule

A research round is not considered operationally closed until:
1. important evidence and conclusions are landed in the SSOT;
2. Research Transaction is written;
3. repository/web validation has passed or the unresolved failure is explicitly recorded;
4. the Goal Regression Checkpoint has been reported to the user.
